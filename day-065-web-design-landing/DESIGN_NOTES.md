# Day 65 - Web design notes (my own summary)

This landing page applies these principles:

1. **Colour theory:** one primary colour (green, which suggests growth), one accent for calls to action, and neutral paper/ink colours for text. The palette is kept to three or four colours.
2. **Typography:** a serif body font for readability, a sans-serif for headings and buttons for contrast, with no more than two families. Heading sizes are fluid with `clamp()`.
3. **User interface design:** a clear hierarchy (one headline, one main call to action), consistent spacing, and alignment on a single grid.
4. **User experience:** short, benefit-led copy; the main action sits above the fold; the layout is responsive with `auto-fit` grid columns; nothing moves unexpectedly.
5. **Web design components:** hero, feature cards, social proof (testimonial) and footer.

Checklist before shipping a page:
- [ ] Is there one obvious primary action?
- [ ] Do text and background have enough contrast (WCAG AA)?
- [ ] Does it work on a 360 px wide phone?
- [ ] Are there at most two font families and four colours?
- [ ] Do images have alt text, and does the page work without them?
