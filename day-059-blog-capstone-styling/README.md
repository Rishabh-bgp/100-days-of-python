# Day 59: Blog Capstone pt 2

Day 59 - Blog Capstone part 2: a styled multi-page blog (home, post, about, contact)
using template inheritance and Bootstrap 5 (served locally via Bootstrap-Flask).

Run with:  flask --app app run

**Topic:** Styling a blog

**Concepts:** template inheritance, Bootstrap theme

## Files

- `app.py`
- `posts.json`
- `requirements.txt`
- `templates/`

## Run

```bash
pip install -r requirements.txt
flask --app app run      # then open http://127.0.0.1:5000
```
