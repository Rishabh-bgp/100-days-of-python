# Day 62: Coffee & Wi-Fi

Day 62 - Coffee & Wi-Fi: a Flask-WTF form with URL validation and select fields that
appends cafes to a CSV, plus a table page that renders the CSV.

Run with:  flask --app app run

**Topic:** Flask-WTF + CSV

**Concepts:** forms, CSV storage, tables

## Notes

Bootstrap-Flask replaces Flask-Bootstrap.

## Files

- `app.py`
- `cafe-data.csv`
- `requirements.txt`
- `templates/`

## Run

```bash
pip install -r requirements.txt
flask --app app run      # then open http://127.0.0.1:5000
```
