# Day 18: Hirst Spot Painting

Day 18 - Hirst-style spot painting with turtle (tuples, modules, aliases).

The course extracts colours from an image with the third-party 'colorgram' package;
this version uses a hand-picked palette so it needs only the standard library.

**Topic:** Turtle & GUIs

**Concepts:** turtle graphics, tuples, modules, aliases

## Notes

Hand-picked palette replaces `colorgram` colour extraction.

This project opens a window (tkinter/turtle), so it needs a desktop session. On Linux you may need `sudo apt install python3-tk`.

## Files

- `exercises.py`
- `main.py`

## Run

```bash
python main.py
python exercises.py
```
