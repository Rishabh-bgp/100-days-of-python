# Day 31: Flash Card App

Day 31 - Flash Card app: tkinter + pandas, flipping a card with window.after().

Card faces are drawn on the canvas (the course uses image assets).

**Topic:** Capstone 3

**Concepts:** tkinter + pandas, timers, persisting progress

## Notes

Original French word list; card faces drawn on canvas.

This project opens a window (tkinter/turtle), so it needs a desktop session. On Linux you may need `sudo apt install python3-tk`.

## Files

- `deck.py`
- `french_words.csv`
- `main.py`
- `requirements.txt`

## Run

```bash
pip install -r requirements.txt
python main.py
```
