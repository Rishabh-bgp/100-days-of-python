# Day 34: Quizzler

Day 34 - Quizzler: a tkinter GUI for the quiz, with type hints and class-based UI.

API-free: questions come from the bundled questions.json instead of the Open Trivia DB API.

**Topic:** GUI + type hints

**Concepts:** class-based tkinter UI, type hints, html.unescape

## Notes

API-free (replaced Open Trivia DB with bundled questions.json).

This project opens a window (tkinter/turtle), so it needs a desktop session. On Linux you may need `sudo apt install python3-tk`.

## Files

- `main.py`
- `questions.json`
- `quiz_brain.py`

## Run

```bash
python main.py
```
