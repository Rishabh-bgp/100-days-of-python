# Day 86: Breakout

Day 86 - Portfolio project: Breakout with turtle. Arrow keys move the paddle; clear all
the bricks. You have 3 lives; score shown at the top.

**Topic:** Portfolio

**Concepts:** turtle game, collisions

## Notes



This project opens a window (tkinter/turtle), so it needs a desktop session. On Linux you may need `sudo apt install python3-tk`.

## Files

- `breakout.py`
- `main.py`

## Run

```bash
python main.py
```
