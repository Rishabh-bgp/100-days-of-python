# Day 89: Disappearing Text Writing App

Day 89 - Portfolio project: the 'most dangerous writing app'. Keep typing - if you stop
for 5 seconds, everything you wrote disappears. A progress bar shows the countdown and you
can save your text once you reach the word goal.

**Topic:** Portfolio

**Concepts:** tkinter timers

## Notes



This project opens a window (tkinter/turtle), so it needs a desktop session. On Linux you may need `sudo apt install python3-tk`.

## Files

- `main.py`

## Run

```bash
python main.py
```
