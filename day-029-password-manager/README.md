# Day 29: Password Manager

Day 29 - Password Manager (tkinter): generate, copy and save passwords to a local file.

Saved entries go to data.txt next to this script (git-ignored). Clipboard copy uses
tkinter's own clipboard instead of the third-party 'pyperclip'.

**Topic:** tkinter layout

**Concepts:** grid, messagebox, clipboard, file append

## Notes

tkinter clipboard replaces `pyperclip`.

This project opens a window (tkinter/turtle), so it needs a desktop session. On Linux you may need `sudo apt install python3-tk`.

## Files

- `main.py`

## Run

```bash
python main.py
```
