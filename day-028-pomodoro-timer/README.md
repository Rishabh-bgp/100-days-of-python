# Day 28: Pomodoro Timer

Day 28 - Pomodoro Timer: tkinter canvas, window.after() event loop, dynamic typing.

The course draws a tomato image; here the tomato is drawn with canvas shapes.

**Topic:** tkinter events

**Concepts:** canvas, window.after, dynamic typing

## Notes

Tomato drawn on the canvas instead of an image asset.

This project opens a window (tkinter/turtle), so it needs a desktop session. On Linux you may need `sudo apt install python3-tk`.
