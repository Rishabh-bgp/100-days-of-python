# Day 85: Typing Speed Test

Day 85 - Portfolio project: typing speed test (tkinter). The timer starts on your first
keystroke; press Enter to finish and see gross WPM, net WPM and accuracy.

**Topic:** Portfolio

**Concepts:** tkinter events, timing, WPM

## Notes



This project opens a window (tkinter/turtle), so it needs a desktop session. On Linux you may need `sudo apt install python3-tk`.

## Files

- `main.py`
- `typing_core.py`

## Run

```bash
python main.py
```
