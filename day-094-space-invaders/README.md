# Day 94: Space Invaders

Day 94 - Portfolio project: Space Invaders with turtle. Left/Right to move, Space to
shoot. Clear the fleet before it reaches you; alien shots cost a life (3 lives).

**Topic:** Portfolio

**Concepts:** turtle game, classes

## Notes



This project opens a window (tkinter/turtle), so it needs a desktop session. On Linux you may need `sudo apt install python3-tk`.

## Files

- `invaders.py`
- `main.py`

## Run

```bash
python main.py
```
